# TQuiz Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Сайт для живых квизов: редактор квизов и пульт ведущего (`/admin`), общий экран (`/screen`), телефон команды (`/play`); туры «Своя игра» и «Свободный ввод».

**Architecture:** Один процесс FastAPI. Игровая логика — чистый Python-класс `Game` (без IO, полностью покрыт тестами), состояние — pydantic-модель, сохраняется JSON-ом в SQLite после каждого изменения. `Hub` держит единственную игру, принимает команды по WebSocket, после каждого изменения шлёт каждой роли полный снимок её представления (`admin_view` / `screen_view` / `team_view` — фильтрация скрытых данных здесь). React SPA (Vite) с тремя маршрутами раздаётся тем же FastAPI. Деплой: docker compose (app + Caddy).

**Tech Stack:** Python ≥3.12, FastAPI, uvicorn, SQLModel (SQLite), pydantic-settings, pytest, uv · React 18, TypeScript (strict), Vite 5, react-router-dom 6, qrcode.react 4 · Docker, Caddy 2.

**Spec:** `docs/superpowers/specs/2026-11-18-tquiz-design.md` (наброски экранов: `docs/superpowers/specs/mockups/`). Исполнитель читает спеку целиком перед первой задачей.

## Global Constraints

- Один процесс, без Redis/очередей/фоновых воркеров. Одна активная игра.
- Сервер — единственный источник правды; клиенты только рисуют снимок и шлют команды.
- Правильные ответы, `correct_option`, ответы других команд никогда не попадают в `screen_view`/`team_view` до показа; медиа URL никогда не попадают в `team_view`; токены команд — никуда, кроме самой команды при входе.
- Медиа: картинки `jpg jpeg png webp gif` ≤ 10 МБ, аудио `mp3 m4a ogg wav` ≤ 20 МБ; расширение сравнивается без учёта регистра.
- Env: `ADMIN_PASSWORD`, `SECRET_KEY`, `PUBLIC_URL`, `DATA_DIR` (по умолчанию `./data`), `STATIC_DIR` (собранный фронт; пусто — не раздавать), `DOMAIN` (только для Caddy).
- Константы (в `app/game/engine.py`): `FALSE_START_LOCK = 1.0` с, `TIMER_ADD_SECONDS = 10`, `UNDO_LIMIT = 20`, `TEAM_NAME_MAX = 40`; в `app/ws/hub.py`: `TICK_INTERVAL = 0.2` с.
- Значения по умолчанию тура: своя игра — `minus_on_wrong=False`, `buzzer_mode="bar"`, `bar_seconds=5`; свободный ввод — `discuss_seconds=60`, `input_seconds=15`, `stakes=False`. Номинал вопроса по умолчанию 1.
- Все моменты времени — абсолютные секунды `time.time()` (float). Каждый снимок содержит `now` сервера; клиенты считают таймеры/полоски через смещение `now_server − Date.now()/1000`, а не по своим часам.
- Интерфейс и тексты ошибок (`GameError`, `HTTPException.detail`) — на русском; код, идентификаторы, имена команд протокола — на английском.
- От команды один телефон; вход в существующую команду с нового устройства — только через подтверждение ведущего.
- Команды разработки: бэк `cd backend && uv run pytest`, `uv run uvicorn --factory app.main:create_app --reload --port 8000`; фронт `cd frontend && npm run dev`, `npm run build`.

## Review Focus

1. **Телефон теряет WebSocket** (iOS блокировка экрана, встроенный браузер Telegram/VK, смена Wi-Fi ↔ LTE): клиент обязан сам переподключиться с токеном и не потерять набранный черновик ответа. → тест `test_team_reconnects_with_token` (Task 9) + ручная проверка в Task 12, шаг «блокировка телефона».
2. **Ответ отправлен в последнюю долю секунды**, а тик таймера ещё не прошёл: сервер обязан отклонить ответ после дедлайна, даже если `tick()` не вызывался. → `test_answer_rejected_after_deadline_even_without_tick` (Task 6).
3. **Медиа с iPhone**: `.JPG`/`.MP3` в верхнем регистре должны приниматься; `.HEIC` — отклоняться понятным сообщением, а не 500. → `test_upload_uppercase_extension_ok`, `test_upload_heic_rejected_with_hint` (Task 4).
4. **Повторный ввод того же названия** с другим регистром/пробелами («Котики » vs «котики») — это запрос на возврат, а не вторая команда. → `test_join_same_name_case_insensitive_creates_rejoin_request` (Task 5).
5. **Ведущий удаляет команду**, которая сейчас отвечает или выбирает в своей игре — состояние остаётся согласованным (кнопки снова открываются у остальных / выбирающий сбрасывается). → `test_delete_answering_team_reopens_buttons`, `test_delete_chooser_clears_chooser` (Task 7).

- `start`: `chooser_team_id` = команда с наименьшим счётом, при равенстве — раньше вошедшая; `None`, если команд нет.
- `SetChooser`: в фазе `board`/`answer`.
- `OpenCell(qid)`: фаза `board` или `answer`; вопрос из текущего тура и не в `played` (GameError «Вопрос уже сыгран»). Сброс `excluded, buzzes, lockouts, answering_team_id, secret_recipient_id`; `played.append(qid)`; `question_id=qid`. Секрет → `phase="secret"`, `buttons="closed"`. Иначе `phase="question"`; `instant` → `buttons="open"`; `bar` → `buttons="bar"`, `bar_ends_at = now + bar_seconds`. `game.audio_for(question)`.
- `tick`: `buttons=="bar"` и `now >= bar_ends_at` → `open`, `bar_ends_at=None`, True.
- `OpenButtons`: `bar` → `open`.
- `BuzzCmd` от команды (молча игнорируется, без GameError, если нажимать нельзя): фаза `question` без получателя секрета, команда не в `excluded`.
  - `buttons=="bar"` → фальстарт: `lockouts[team] = now + FALSE_START_LOCK`.
  - `buttons=="open"` и `lockouts.get(team, 0) <= now` → `answering_team_id=team`, `buttons="locked"`, `buzzes.append(Buzz(team, now))`; если у вопроса аудио — `set_audio("pause")`.
  - `buttons=="locked"` и команды ещё нет в `buzzes` и она не отвечает → только `buzzes.append(...)` (для справки ведущему).
- `SetSecretRecipient(team)`: фаза `secret`; `team != chooser` (GameError «Секрет нужно отдать другой команде»); `secret_recipient_id=answering_team_id=team`, `phase="question"`, `buttons="closed"`.
- `Judge(correct)`: нужен `answering_team_id` (GameError «Никто не отвечает»); `value = question.value`.
  - верно: `+value`; `phase="answer"`, `buttons="closed"`; `chooser = answering`.
  - неверно: если `minus_on_wrong` — `-value`; `excluded.append(answering)`, `answering=None`. Если это секрет или все текущие команды в `excluded` → `phase="answer"`, `buttons="closed"` (выбирающий не меняется). Иначе `buttons="open"`, `buzzes=[]`, `lockouts={}` (без полоски).
- `Reveal`: из `question`/`secret` → `phase="answer"`, `buttons="closed"`, `answering=None`.
- `ToBoard`: → `phase="board"`, `question_id=None`, `buttons="closed"`, `set_audio("stop")`.
- `on_team_deleted`: убрать из `excluded`, `lockouts`, `buzzes`; если был `chooser` → `None`; если был `answering` → как неверный ответ без изменения счёта (кнопки снова открываются, либо `phase="answer"`, если отвечать больше некому или это секрет).
- `buzzer_status(team)`: не `question` → `closed`; `answering == team` → `answering_me`; `answering` другой → `answering_other`; в `excluded` → `excluded`; `lockouts[team] > now` → `locked_out`; `buttons=="bar"` → `bar`; `open` → `open`; иначе `closed`.
