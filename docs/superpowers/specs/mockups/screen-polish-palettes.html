Какая палитра ближе?

Слева вопрос свободного ввода с таймером, справа табло своей игры. Узоры по краям здесь условные: на их месте будет твоя картинка-фон, центр остаётся спокойным. D — мягкий тёмный вариант для сравнения (тёмный зал, ТВ). Цвета полоски таймера — свои у каждой палитры. Кликни понравившуюся, можно несколько.
